# 📊 医药电商日报模板（自动计算版）

一个为医药电商运营量身打造的Excel日报模板，每天只需要填4个原始数据，剩下的全部自动计算。

---

## ✨ 功能特点

- **5个店铺 + 汇总列**，一目了然
- **只需填写4项原始数据**：总单量、总支付金额、产品成本、推广费用
- **自动计算**：产品运费、平台佣金、电商税、收入、推广费比、毛利率
- **汇总自动求和**，不用手动加总
- **颜色分区**：绿色表头、白色输入、黄色结果

---

## 📋 使用步骤

1. 打开 `医药电商日报模板_自动计算版.xlsx`
2. 修改 C1 单元格的日期为当天
3. 填写第3-6行的白色单元格（4个原始数据）
4. 黄色单元格自动出结果，收工
